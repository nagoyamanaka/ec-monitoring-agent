## 制作注意事項（BGM・テロップ）— AI審査前提

> AI審査員は ASR（音声文字起こし）＋フレーム OCR/画像理解で評価しうる。**ナレーションの明瞭さ**＋**テロップの機械可読性**＋**UIの可視性**を三立させる。

### テロップ方式（U7 = ハイブリッド）

- **キーワード名札**: 各シーンの頭で「今どの画面か」を 1〜2 語で大きく提示（画面端・UIを隠さない位置）。ナレ全文の複写はしない。
- **信頼性フレーズ**: UIモーションで自明にならない差別化（実在シグナル照合・実在証拠・偽引用ドロップ・批判役・次のアクション）は**短文テロップで残す**。無音・倍速視聴でも最大の売りが伝わるように。最低2箇所（予報の引用・調査の証拠）。
- **表示ルール**: テロップは 1 行・最大 ~14 字・画面下端 or 右上に小さめ・0.7 透過帯（`rgba(11,18,32,0.7)`）で UI と混色しない。**同時に画面内テキストを2つ以上出さない**（読ませすぎない）。
- 絵文字はテロップに不使用（take002 の豆腐化の教訓）。
- 倍速バッジ: 右上に「×N倍速」（調査カットの実測区間）を白太字で常時表示。どこを速めたかの正直な明示。

### BGM（初版設計のまま有効）

- 入れてよいが条件付き（無しでも減点なし・情緒演出曲は不可）。インスト／ナレピーク比 −20dB 以下／全体 −14 LUFS 目安。無ナレ区間（カット0）のみ +3〜6dB 可。迷ったら無し。
